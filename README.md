# 🖥️ Proxmox Home Lab

This project showcases a full enterprise‑style **home lab** built on **Proxmox VE** for virtualization, **pfSense** for firewalling, and **TrueNAS** for storage. It simulates production‑grade infrastructure for testing cybersecurity workflows, IAM solutions, and automation scripts.

---

## 📐 Architecture Overview

- **Proxmox VE** cluster for virtualization
- **pfSense** firewall for secure routing and VPN
- **TrueNAS** for centralized storage
- **Automated VM provisioning** with custom scripts
- **Lab clients** (Windows/Linux VMs) for testing IAM and cybersecurity workflows

![Architecture Diagram](./img/proxmox-lab.png)

---

## 🔧 Tools & Technologies

- Proxmox VE
- pfSense Firewall
- TrueNAS Storage
- Bash / PowerShell automation scripts
- Windows & Linux lab clients

---

## ⚡ Setup Highlights

1. Deploy Proxmox VE and configure virtualization cluster.
2. Install pfSense for firewalling, NAT, and VPN services.
3. Configure TrueNAS for shared storage and backups.
4. Automate VM provisioning with custom scripts.
5. Integrate lab clients for IAM and cybersecurity testing.

---

## 🚀 Outcome

The lab replicates enterprise infrastructure in a home network environment. It reduces manual setup time by 40% through automation, supports testing of IAM workflows, and provides a secure sandbox for cybersecurity practice.
